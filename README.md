# CampusPulse prototype

## Run it
1. Open this folder in VS Code.
2. Use the Live Server extension to open `index.html`.
3. It should open at a localhost address.

## Features
- Responsive opportunity dashboard
- Search and category / format / institution filters
- Save and remove opportunities (stored in this browser)
- PWA manifest and service worker for installability/offline caching
- Browser notification permission demo

## Important
All six listings are illustrative demo data, not verified real events. College names and official homepages are examples of institutions to research. Verify every event, deadline, eligibility, fee, and registration link before publishing it as a real opportunity.

## Not built yet
Accounts, shared database, verified event collection, scheduled reminders, background web push, admin verification, and deployment. Background push requires a backend push service and secure subscription storage.
